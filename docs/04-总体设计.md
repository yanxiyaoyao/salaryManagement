# 个人开支记账管理系统 - 总体设计

## 1. 系统架构设计

### 1.1 整体架构

系统采用前后端分离的B/S架构，分为三层：

```
┌─────────────────────────────────────────────────────┐
│                   表现层（Frontend）                   │
│  React + Redux + React Router + Ant Design + Sass   │
└─────────────────────────────────────────────────────┘
                          ↕ (HTTP/HTTPS)
┌─────────────────────────────────────────────────────┐
│                   业务层（Backend）                    │
│     Flask + SQLAlchemy + Flask-JWT-Extended         │
└─────────────────────────────────────────────────────┘
                          ↕ (SQL)
┌─────────────────────────────────────────────────────┐
│                   数据层（Database）                   │
│                    SQLite 3.x                        │
└─────────────────────────────────────────────────────┘
```

## 4. 后端设计

### 4.1 API设计原则

- **RESTful风格**：使用HTTP方法表示操作
- **统一响应格式**：所有API返回统一的JSON格式
- **版本控制**：API路径包含版本号（/api/v1/）
- **错误处理**：统一的错误响应格式
- **认证授权**：使用JWT进行身份认证

### 4.2 响应格式

**成功响应：**

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    // 业务数据
  }
}
```

**错误响应：**

```json
{
  "code": 400,
  "msg": "错误信息",
  "data": null
}
```

### 4.3 认证流程

```
1. 用户登录
   POST /api/auth/login
   Request: {username, password}
   Response: {token, user}

2. 存储Token
   localStorage.setItem('token', token)

3. 发送请求
   Header: Authorization: Bearer <token>

4. 服务器验证
   验证Token有效性
   提取用户身份信息

5. 处理请求
   返回用户相关数据
```

### 4.4 错误处理

| 错误码 | 说明 | HTTP状态码 |
|--------|------|-----------|
| 200 | 成功 | 200 |
| 400 | 请求参数错误 | 400 |
| 401 | 未认证 | 401 |
| 403 | 无权限 | 403 |
| 404 | 资源不存在 | 404 |
| 409 | 冲突（如用户名已存在） | 409 |
| 500 | 服务器错误 | 500 |

## 5. 安全设计

### 5.1 认证安全

- **密码哈希**：使用werkzeug.security进行密码哈希
- **JWT签名**：使用密钥对Token签名
- **Token过期**：设置Token过期时间为1小时
- **HTTPS**：生产环境使用HTTPS加密传输

### 5.2 授权安全

- **访问控制**：用户只能访问自己的数据
- **路由保护**：受保护的路由需要有效Token
- **数据隔离**：数据库查询自动过滤用户数据

### 5.3 数据安全

- **SQL注入防护**：使用ORM防止SQL注入
- **XSS防护**：React自动转义HTML内容
- **CSRF防护**：使用Token验证防止CSRF攻击

### 5.4 文件上传安全

- **文件类型验证**：仅允许上传图片文件
- **文件大小限制**：限制上传文件大小
- **文件名处理**：重命名上传的文件

## 6. 性能设计

### 6.1 前端性能优化

- **代码分割**：使用动态导入实现路由级别的代码分割
- **组件懒加载**：使用React.lazy实现组件懒加载
- **缓存策略**：缓存API响应数据
- **虚拟滚动**：大列表使用虚拟滚动

### 6.2 后端性能优化

- **数据库索引**：为常用查询字段添加索引
- **查询优化**：使用关联加载避免N+1查询
- **缓存**：对频繁访问的数据进行缓存
- **分页**：大数据集使用分页查询

### 6.3 网络优化

- **资源压缩**：压缩CSS、JS、图片文件
- **CDN加速**：使用CDN加速静态资源
- **请求合并**：合并多个API请求
- **连接复用**：使用HTTP Keep-Alive
