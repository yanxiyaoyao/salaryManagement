# 个人开支记账管理系统 - 详细设计

## 1. 前端详细设计

### 1.1 认证模块设计

#### 1.1.1 登录页面（Login）

**功能描述：** 用户输入用户名和密码进行登录

**页面结构：**

```jsx
Login
├── Form
│   ├── Input (username)
│   ├── Input (password)
│   └── Button (submit)
├── Link (to register)
└── Error Message
```

**核心逻辑：**

```javascript
1. 用户输入用户名和密码
2. 点击登录按钮
3. 前端验证输入数据
4. 发送POST请求到 /api/auth/login
5. 后端验证用户名和密码
6. 返回Token和用户信息
7. 前端存储Token到localStorage
8. 更新Redux auth状态
9. 跳转到首页
```

**状态管理：**

```javascript
const [username, setUsername] = useState('')
const [password, setPassword] = useState('')
const [loading, setLoading] = useState(false)
const [error, setError] = useState('')
```

**API调用：**

```javascript
POST /api/auth/login
Request: {
  username: string,
  password: string
}
Response: {
  code: 200,
  data: {
    token: string,
    user: {
      id: number,
      username: string,
      nickname: string,
      email: string,
      phone: string,
      avatar: string
    }
  }
}
```

#### 1.1.2 注册页面（Register）

**功能描述：** 新用户创建账户

**页面结构：**

```jsx
Register
├── Form
│   ├── Input (username)
│   ├── Input (password)
│   ├── Input (confirmPassword)
│   └── Button (submit)
├── Link (to login)
└── Error Message
```

**核心逻辑：**

```javascript
1. 用户输入用户名和密码
2. 点击注册按钮
3. 前端验证输入数据
4. 验证两次密码是否一致
5. 发送POST请求到 /api/auth/register
6. 后端检查用户名是否已被占用
7. 创建新用户
8. 返回成功消息
9. 跳转到登录页
```

**验证规则：**

```javascript
- 用户名：长度3-50，只能包含字母、数字、下划线
- 密码：长度6-128，建议包含大小写字母、数字、特殊字符
- 确认密码：必须与密码一致
```

## 2. 后端详细设计

### 2.1 认证模块设计

#### 2.1.1 登录接口

**接口路径：** `POST /api/auth/login`

**请求参数：**

```json
{
  "username": "string",
  "password": "string"
}
```

**响应数据：**

```json
{
  "code": 200,
  "msg": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "id": 1,
      "username": "admin",
      "nickname": "管理员",
      "email": "admin@example.com",
      "phone": "13800138000",
      "avatar": "http://..."
    }
  }
}
```

**业务逻辑：**

```python
1. 获取请求参数（username, password）
2. 验证参数不为空
3. 查询数据库获取用户
4. 验证密码是否正确
5. 生成JWT Token
6. 返回Token和用户信息
```

**错误处理：**

```python
- 用户名或密码为空：400 Bad Request
- 用户不存在或密码错误：401 Unauthorized
- 数据库错误：500 Internal Server Error
```



## 3. 数据库操作设计

### 3.1 查询优化

**使用关联加载避免N+1查询：**

```python
# 不好的做法：N+1查询
transactions = Transaction.query.all()
for tx in transactions:
    category = tx.category  # 每次都查询数据库

# 好的做法：使用关联加载
transactions = Transaction.query.options(
    joinedload(Transaction.category)
).all()
```

**使用分页避免一次性加载大量数据：**

```python
# 分页查询
page = request.args.get('page', 1, type=int)
per_page = request.args.get('per_page', 20, type=int)
paginated = Transaction.query.paginate(page=page, per_page=per_page)
```

```python
try:
```

## 4. 错误处理设计

### 4.1 统一错误响应格式

```python
class APIResponse:
    def __init__(self, code, msg, data=None):
        self.code = code
        self.msg = msg
        self.data = data
    
    def to_response(self):
        return {
            'code': self.code,
            'msg': self.msg,
            'data': self.data
        }
```

### 4.2 错误处理中间件

```python
@app.errorhandler(400)
def bad_request(error):
    return APIResponse(400, '请求参数错误').to_response()

@app.errorhandler(401)
def unauthorized(error):
    return APIResponse(401, '未认证').to_response()

@app.errorhandler(404)
def not_found(error):
    return APIResponse(404, '资源不存在').to_response()

@app.errorhandler(500)
def internal_error(error):
    return APIResponse(500, '服务器错误').to_response()
```
