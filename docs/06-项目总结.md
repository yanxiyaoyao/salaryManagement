# 个人开支记账管理系统 - 项目总结

## 1. 项目概述

本项目是一个功能完整的个人开支记账管理系统，采用前后端分离的架构，使用现代化的技术栈开发。系统提供了用户认证、交易管理、分类管理、数据统计等核心功能，帮助用户有效管理个人财务。

### 5.4 常见问题和解决方案

#### 5.4.1 跨域问题

**问题：** 前端请求后端API时出现跨域错误

**解决方案：**

```python
from flask_cors import CORS

CORS(app, resources={
    r"/api/*": {
        "origins": "*",
        "methods": ["GET", "POST", "PUT", "DELETE", "OPTIONS"]
    }
})
```

#### 5.4.2 Token过期问题

**问题：** Token过期后用户需要重新登录

**解决方案：**

- 在响应拦截器中检查401错误
- 自动跳转到登录页
- 提示用户重新登录

```javascript
api.interceptors.response.use(
  response => response,
  error => {
    if (error.response?.status === 401) {
      // 跳转到登录页
      window.location.href = '/login'
    }
    return Promise.reject(error)
  }
)
```

#### 5.4.3 性能问题

**问题：** 大数据量查询时性能下降

**解决方案：**

- 使用分页查询
- 添加数据库索引
- 使用关联加载避免N+1查询
- 实现缓存机制

#### 5.4.4 数据一致性问题

**问题：** 并发操作时数据不一致

**解决方案：**

- 使用数据库事务
- 使用乐观锁或悲观锁
- 实现版本控制
